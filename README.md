# Odin Landing Page - Orphan Kitten Club 🐱

This project is a static landing page built as part of [The Odin Project](https://www.theodinproject.com/) Web Development Fundamentals curriculum.

The primary goal of this assignment was to practice and demonstrate proficiency in HTML structure, CSS Flexbox layouts, the CSS Box Model, and positioning techniques based on a provided design specification.

While the current version satisfies the Odin Project submission requirements, the project theme is styled around **Orphan Kitten Club**—a cat adoption concept that I plan to expand with more feature-complete content and interactive elements in the future.
